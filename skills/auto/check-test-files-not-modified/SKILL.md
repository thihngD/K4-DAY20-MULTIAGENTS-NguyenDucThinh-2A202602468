---
name: check-test-files-not-modified
description: Use this skill to ensure that original test files are not modified during updates.
---
1. Identify all test files in the designated test directory.
2. Create a backup of each test file before making any modifications.
3. Implement changes only in new test files or separate test cases.
4. Verify that no original test files have been altered after the changes.
5. Document any new test files created in the changelog.
