---
name: document-changelog-updates
description: Use this skill to ensure all changes are documented in the changelog.
---
1. Identify all changes made to the codebase, including bug fixes and new features.
2. For each change, create a bullet point summarizing the modification.
3. Organize the bullet points under the '## Unreleased' section of the CHANGELOG.md file.
4. Ensure that each bullet point follows the format: '- fix(<function name>): <short description>'.
5. Review the changelog for clarity and completeness before finalizing.
