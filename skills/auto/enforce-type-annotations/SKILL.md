---
name: enforce-type-annotations
description: Use this skill to ensure all public functions have type annotations for parameters and return values.
---
1. Review all public functions in the codebase.
2. Check for the presence of type annotations on each parameter and the return value.
3. If any function lacks type annotations, add appropriate types based on the function's logic.
4. Ensure that the added annotations are consistent with the overall code style.
5. Run static type checkers to validate the correctness of the annotations.
